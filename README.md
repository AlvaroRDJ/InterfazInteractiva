# Interfaz interactiva con navegación

App Android en Kotlin con dos pantallas: un formulario de registro y una pantalla de resultado. Es la Tarea 4 del módulo de Programación Multimedia y Dispositivos Móviles (FP).

## Qué hace

- **Pantalla 1:** formulario con nombre, edad, tecnologías (Java y Kotlin) y turno (mañana o tarde).
- **Validación:** si el nombre o la edad están vacíos, muestra un mensaje de aviso.
- **Pantalla 2:** muestra los datos recibidos y tiene un botón para volver.

## Lo que he practicado

- Componentes de interfaz: TextView, EditText, CheckBox, RadioGroup y Button
- Layouts en XML
- Listeners con setOnClickListener
- Paso de datos entre Activities con Intent, putExtra y getStringExtra

## Cómo probarlo

1. Clona el repositorio o descárgalo como ZIP.
2. Ábrelo con Android Studio.
3. Espera a que Gradle termine de sincronizar.
4. Ejecuta la app en un emulador o en un móvil.

## Estructura

- MainActivity.kt: pantalla del formulario
- Resultado.kt: pantalla de resultado
- res/layout: diseños en XML de ambas pantallas
